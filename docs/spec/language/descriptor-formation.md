six installed structural schemes over existing Finite leaves. It grants no

Natural implication permits nonnegative coefficient domination directly or

One immutable arena owns generic payloads and persistent chunked AVL sequence

Shared templates retain each ordered invocation edge; repeated calls yield

A selected Finite result projects every activated Finite formation occurrence,

## Closed source export

The formation envelope below is internal native transport pending joint
source-association and independent strict-reader review before publication.
It does not establish an independent semantic consumer profile.

The outer `zkc.source-instances/0` schema is unchanged. Closed Finite arguments
retain the `{inputs,nodes,result}` grammar. Ordered formation occurrences can
change emitted graphs and admission work: equal authored applications remain
separate assertions, and repeated invocations can reach the native node limit.
Source/body associations must refer to the actual emitted graph. A structural
argument has exactly `format`,
`contract`, `inputs`, `leaves`, `payloads`, `sequences`, `blocks`, `payload` and
`formation`, with format `zkc.descriptor-formation/0`.

Contracts use the exact contextual static-term grammar:
`["descriptor-product", [descriptor...]]` and
`["descriptor-sequence", descriptor, null | ["nat", canonical-decimal]]`.
Finite remains `["builtin", "finite", [term]]`. The independent native wire
readers own these tags and their unchanged limits. This adds no native family.
`leaves` uses the existing complete Finite node schema;
children select prior leaf templates. Payloads have `contract` and `kind`, plus
`leaf` for `finite`, ordered `elements` for `product`, or nullable `root` for
`sequence`. Sequence cells have exactly `length`, `height`, nullable `left` and
`right`, and `elements`; empty sequences have a null root. Chunk cells have
null children; branches have empty elements and prior cell children.

`blocks` is an ordered array of ordered occurrence arrays. Each occurrence has
exactly `kind`, nullable `expression`, `result`, `children`, nullable
`invocation` and `authority`. Kind spellings distinguish `ordered_product`
from the existing Finite `product`. Invocation edges select shared blocks;
they must be acyclic and retain every use. Payload and formation select the
result and source block independently. Authority is the lowercase hexadecimal
encoding of the internal binary lookup identity, never a substitute for
relational source checking. Source residuals cannot export.
The occurrence `expression` ordinal is local to the exact retained syntax
snapshot; it is not a cross-parser WrittenSource address. A semantic reader
must bind it to the canonical owner/path inventory, capture, installation and
source revision. Sequence cell layout/height and authority strings are
non-authoritative transport metadata. Independent consumers derive ordered
elements, contracts, input origins and per-invocation coverage without trusting
AVL rotations or lookup identities, and retain bounded sharing rather than
flattening every historical sequence.
Readers must reject unknown versions, fields, kinds and out-of-range indices;
an old reader must not reinterpret this envelope as a Finite graph.

The Lean-owned strict reader and independent interpretation are separate parent
