# Relations Semantic Profile

> **Document kind:** Publication routing index
> **Document state:** Active non-normative target
> **Provisional owner:** `relations`
> **Authority:** None during transition. Current normative relation semantics
> remain under [`docs/`](../../../docs/README.md).

[`relations.json`](relations.json) publishes the one bounded
`relations.correspondence` language profile from exact marked fragments in the
Relation Model, Protocol Correspondence, and Recursive-Composition Grounding
owners. It imports exactly PIR Interaction and Interface/Plan because the
Relations laws open both bodies directly.

The profile contains 24 semantic-subject kinds. The separate 14-kind module
declaration-contract namespace remains part of the Relations law source and is
not reclassified as profile-local semantic subjects.

Foundation owns the reusable [publication mechanism](../../foundation/semantic-profile-publication.md),
the complete [manifest index](../../foundation/semantic-profile-manifests.json),
and independent reconstruction of the derived identity table.
Publication fixes deterministic language identity; it proves no relation
satisfaction, correspondence result, theorem, or implementation conformance.
