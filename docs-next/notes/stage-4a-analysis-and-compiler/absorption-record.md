## 1. Closure result

Stage 4A selects one ordered architecture:

```text
family-owned semantic question
  + exact admitted subjects, views, model, and hypotheses
  + exact semantic, support, and validation bases
  -> qualified family-specific Analysis judgment

exact transform problem and decision policy
  -> open unauthoritative production
  -> frozen proposal scope
  -> per-alternative independent PIR admission and transition qualification
  -> total alternative resolution
  -> semantic CandidateDomain D
  -> total qualification resolution
  -> comparison-alternative domain Q
  -> total assessment accounting
  -> checked decision sufficiency -> bounded qualified Compiler decision

checked DecisionPolicy + any exact reached qualified subset
  + exact reached closure results actually read + audit-relative accounting
  -> independently checked honest open report

preparation or checking failure at any reached operation -> outer outcome
```

Candidate B supplies the semantic center: federated typed Analysis followed by
a five-plane validated-decision Compiler. The selected model also absorbs
bounded mechanisms from the controls:

- Candidate A's closed native rule bodies, exact arithmetic, explicit
  derivation DAGs, and no-search checking;
- Candidate C's dependency and replay graph without universal Claim-IR
  authority;
- Candidate D's checked external-statement, model, proof, and checker
  adapters; and
- Candidate E's optional proof-carrying proposals, relational synthesis,
  symbolic compression, and anytime-report lanes.

The symbolic v0 lane ranges only over an already materialized,
PIR-admitted, transition-qualified `CandidateId` image. A lazy domain over
unnamed or unadmitted Protocols would reopen the Stage 3 subject and admission
boundary and is not selected here.

The selected model is promoted as non-normative target architecture. Current
authority remains under `docs/`. Stage 4A establishes no proposition truth,
cryptographic theorem, compiler correctness, implementation correspondence,
migration plan, endpoint fact, reliance decision, or Stage 4B activation.

   correspondence owner or is intentionally retired;

4. no durable page links to an individual Stage 4A work product;

   manifest entries, headings, fences, tables, and metadata valid; and

temporary directory while the gate is open. That edge exposes status and
