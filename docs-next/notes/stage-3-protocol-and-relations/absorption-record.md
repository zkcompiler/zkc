## 1. Closure result

Stage 3 selected one integrated architecture:

```text
finite language-independent InteractiveCore
  + exactly one challenge interpretation
  = Protocol
      <-> one physically canonical bijective MLIR PIR carrier

Protocol
  +--> independently identified ProtocolInterface
  +--> independently identified ProverPlan
  +--> Relations-owned bindings and checked correspondence
  +--> checked Fresh-to-Fiat--Shamir construction
  `--> checked semantic Core composition
```

Candidate C is the v0 semantic center. Candidate D contributes a finite typed
event/effect technique without becoming a universal event runtime. Candidate
E remains a possible authoring overlay whose closed outputs use the selected
center. Candidate A remains the rich semantic-quotient reopening control, and
Candidate B remains the normative-bundle reopening control.

The selected model is promoted as a non-normative target. Current authority
remains under `docs/`; implementation correspondence, migration, normative
cutover, cryptographic theorems, Analysis judgments, OIR projection results,
and endpoint support were not established.

## 5. Deliberate downstream deferrals

The following are assigned rather than omitted:

- Stage 4A owns exact Analysis questions, models, theorem/rule and assumption
  bases, derivations, judgments, `FSCompile`, composition properties, and
  property-specific transport; Compiler follows over independently admitted,
  relation-checked candidates.
- Stage 4B owns OIR grammar and behavior, local admission,
  `ProjectionCorrect`, exact output exposure and availability, and Plan
  placement; Realization follows with supplier, production, deployment,
  invocation, occurrence, and runtime authority.
- Stage 5 tests the joined cross-system capability surface and is a principal
  reopening point for stronger packages or shared mechanisms.
- Stage 6 owns Evidence, appraisal, and reliance.
- Stage 7 consolidates normative v0 ownership and performs explicit authority
  cutover.
- Stage 8 maps the normative design to implementation architecture,
  conformance, and migration work.

Concrete byte encodings, digest algorithms, historical compatibility windows,
checker implementations, cryptographic proofs, endpoint profiles, provider
bindings, deployments, and runtime evidence remain outside Stage 3.
