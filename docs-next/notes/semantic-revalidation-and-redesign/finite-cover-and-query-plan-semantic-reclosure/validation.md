architecture.

The finite-cover lane now separates three different obligations:

1. exhaustive coverage of the 308-member accepted quotient;
2. universal factorization of the exact raw `Nat64` predicate and candidate

3. transfer from representative success to raw-member success.

premise. The validation basis binds every executed operation to an exact
portable-algorithm identity or property-profile law body, including raw-domain,
normalization, quotient-factorization, and success-transfer checks.

The query-plan lane now fixes one explicit prime-field algebra profile, the
Foundation operational outcome partition, componentwise resource bounds,
transitive visibility, and effect-sensitive answer taint. Earlier source
answers may enter post-read pure value computation but may not affect
activation, routing, requested indices, or nested query control. A prior
logical result is exposed only by one unconditional total-return producer and
aliases its existing Core value; no logical-result event is invented.

The activation-and-prior-result witness checks that rule against a nine-event
flat-Core body authored in a module that imports neither the reference model
nor its elaborator. Reordering or substituting that Core fails before an
affirmative elaboration can be issued.
