# Semantic Closure and Freeze Program

> **Kind:** Temporary research-package index and execution contract
> **State:** Complete; post-freeze research is routed separately
> **Authority:** None. Durable target semantics remain owned by their domain
> pages; this package records method, evidence, decisions, and open work only.
> **Deletion rule:** Absorb every retained conclusion into its durable owner and
> delete this package before documentation cutover.

## Objective

Turn the selected semantic architecture into an independently reconstructible
freeze candidate without treating existing prose, passing fixtures, or review
agreement as semantic authority.

The work proceeds through four dependency barriers:

1. **Semantic closure preflight:** close known contradictions, undefined
   identity-bearing carriers, nondeterministic outcome rules, and rendering
   defects; add executable counterexamples and one uncapped aggregate gate.
2. **Owner-profile publication:** publish complete profile preimages bottom-up,
   with exact import closure, law ownership, support decisions, comparison and
   rotation rules, and independent reconstruction.
3. **Recursive-composition boundary research:** decide digest coverage,
   continuation-family uniformity, IVC theorem application, outstanding
   obligations, CycleFold elaboration, and serialized handoff disposition.
4. **Dependent-profile publication and freeze synthesis:** publish Plan/OIR,
   Relations, and Analysis profiles only after their research dependencies are
   closed, then run holdouts and one bounded independent freeze review.

No barrier is skipped because a later package appears mechanically writable.
Conversely, a closed barrier is not repeatedly reviewed unless a materially new
counterexample reopens it.

## Stable architecture intake

The program preserves the following selected boundaries unless an executable
counterexample or source-faithful construction makes one incoherent:

- `Protocol = InteractiveCore + ChallengeInterpretation`;
- verifier-observable interaction, claims, reductions, and checks belong to
  `InteractiveCore`;
- honest private construction and accepted-terminal continuation belong to
  `ProverPlan`;
- statements, witnesses, satisfaction, and cross-owner correspondence belong
  to Relations;
- theorem premises and property conclusions belong to Analysis;
- endpoint presentation belongs to Interface/OIR; and
- serialization, deployment, and process transport belong to Realization.

Profile publication may rotate identities and rename provisional symbols. It
must not move authority between these owners merely to simplify an encoding.

## Review discipline

Independent agents are falsifiers and research peers, not authorities. A
finding changes the target only after this session reconstructs it from the
owning documents, executable model, and primary source where applicable.

Use focused independent review after semantic preflight and after the complete
freeze candidate. Do not run an unbounded global-review loop after every local
edit. Every review input must state exact claims, nonclaims, known residuals,
and the commit being reviewed.

## Global exit conditions

The program closes only when:

1. every durable semantic definition has one owner and no durable page depends
   on temporary notes;
2. every published profile has a complete independently reconstructible
   preimage and exact import closure;
3. all identity rotations and dependent re-derivations are explicit;
4. the recursive-composition boundary has selected laws or explicit deferrals,
   not implicit claims;
5. holdouts and negative mutations exercise the same public contracts as the
   positive witnesses;
6. the uncapped aggregate gate is green at the checkpoint commit; and
7. one bounded cold review finds no unresolved freeze blocker.

This program establishes no cryptographic theorem, implementation support,
normative cutover, or production readiness.
