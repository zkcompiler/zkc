# Recursive Composition Boundary

> **Kind:** Temporary research-package index and decision record
> **State:** Completed; retained laws absorbed into durable owners
> **Authority:** None. Retained laws must be absorbed by their durable PIR,

> deleted.

## Objective

Close the semantic boundary between one checked protocol step and claims about
many recursive, folding, or accumulation steps without introducing a universal
accumulator, recursive-proof, child-protocol, or transition root.

The package answers six questions:

1. Which recursion-facing instance occurrences must be checked or digest-bound?
2. Which structural conditions make a continuation family uniform without a
   semantic fixpoint?
3. How does an IVC or PCD theorem use the existing Analysis path, and which
   independent depth and random-oracle hypotheses remain explicit?
4. How are deferred decider obligations retained so that an accepting step is
   not reported as unconditional verification?
5. What, if anything, crosses a serialization or process boundary with causal
   handoff authority?
6. Which same-step binding must a complete CycleFold elaboration preserve?

## Working result

The existing owner split remains the starting point:

```text
PIR Plan                 Relations                    Analysis
---------                ---------                    --------
one accepted run         one exact public/private     theorem family,
+ private continuation   recurrence edge              premises, and depth
          |                         |                  qualification
          +------------+------------+----------------------+
                       no inferred induction
```

The leading selection is additive rather than architectural replacement:

- Relations checks complete recursion-facing binding coverage and the exact
  finite recurrence edge;
- PIR admits only statically closed continuation targets and finite
  member-selection inputs;
- Analysis owns derived-obligation meaning and imported IVC/PCD theorem
  application through its existing judgment machinery;
- Realization owns serialization, transport, and fresh re-admission; and
- no serialized value recreates a process-local causal handoff capability.

The owner-separated model is selected and promoted into the durable target
pages. The bounded executable and one independent falsification pass closed
the package without changing the six published upstream PIR profiles.

## Evidence boundary

This package may establish a finite structural design and executable refusal
behavior. It does not establish folding correctness, accumulator validity,
relation satisfaction, an induction theorem, IVC/PCD knowledge soundness,
random-oracle instantiation security, non-malleability, or deployment support.
