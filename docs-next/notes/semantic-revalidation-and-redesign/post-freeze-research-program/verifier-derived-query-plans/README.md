## Question and result

The package asked how a verifier should reuse a logical word whose answer is a
finite pure function of earlier authenticated source Oracles and public or
verifier-private values, without pretending that the prover published or
committed that derived word.

The selected result is a separately identified finite word-program and logical
query-plan language with checked static elaboration into one independently
formed and admitted flat `InteractiveCore`. The elaboration preserves an exact
ordered logical-to-source map and exact bounds. Runtime executes only the flat
Core; the plan is inert structural data.

This selection adds no `OracleOrigin`, Core effect, transcript frame,
commitment root, runtime callback, runtime occurrence allocation, theorem, or
security claim. Answer-adaptive query routing remains outside the profile.
