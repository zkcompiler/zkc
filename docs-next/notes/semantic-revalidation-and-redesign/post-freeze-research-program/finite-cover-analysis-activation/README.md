## Why this is not a generic Schnorr proof

The selected source model deliberately uses `Nat64` surfaces and reduces
commitments and responses inside its verifier. It is not the canonical scalar
and group-element interface specified by the CFRG draft. The result can
establish only fixed-extractor correctness for this exact finite subject and
this exact portable extractor. It establishes no asymptotic special soundness,
knowledge soundness, extractor efficiency, production conformance, security
parameter, Fiat--Shamir theorem, ROM result, or QROM result.

In particular, returning the known witness `3` for the fixed statement `8`
would be extensionally successful on this one subject but would not exercise
the selected extractor. Such a constant-witness candidate is explicitly
rejected. The target binds the response-difference algorithm itself.
