## 1. Purpose

The preceding complete-argument package retained one flat verifier Core and
found two Plan questions that should not be resolved independently:

1. public prover-only parameters that should not enter a deliberately minimal
   verifier Core; and
2. private witness or accumulator material derived after the last verifier
   challenge, when no later Core message exists to create another ordinary
   `ProverDecisionPoint`.

Folding and recursion supply the decisive pressure. They evolve public
relation instances and private witnesses, carry accumulators across runs,
separate accumulation from final decision, and may verify another proof system
inside an outer relation. This package asks whether the current owners can
express those distinctions without a universal accumulator, recursive proof,
or runtime child-Core root.
