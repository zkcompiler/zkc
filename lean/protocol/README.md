# Protocol

The protocol proof framework, fixed property meanings, probabilistic interpretation, component contracts, representation and composition, and reusable mathematical libraries. It depends on Program and mathematical foundations; it does not import concrete IR.

See [architecture](../docs/architecture.md) for ownership, dependencies and extension rules.

Run `lake build` from this directory. Focused module builds use the package's full `Zkc.Protocol` import prefix. Tools and tests are separate targets in this package.
