# Component interfaces and exact installation

The maintained generic interfaces live in the Protocol package. A component fixes
its input/output interpretation and mathematical promises independently of the
source occurrence where it is used. The shared Region/Process construction rules
compose those promises without selecting a different experiment or result meaning.

The concrete IR package independently admits actual source definitions and exposes
typed mathematical references and component declarations. Declaration lookup and
source-visible proposals are data. A matching name or digest is not a proof that a
law applies to that definition, its arguments, captures, roles/services or outcomes.

An installation must fix those actual dependencies and the selected interpretation.
Repeated calls instantiate a named implementation theorem through common construction.
Swapping same-typed handles must fail when it breaks the represented association.
Stateful and probabilistic laws preserve the existing outcome-aware semantics; pure
equations require explicit purity and totality theorems on the relevant domain.

## Current and open boundaries

The generic [source-construction interface](source-construction.md) and its complete
model clients are implemented. Independent structured admission and concrete source
mathematical contracts are retained. The complete actual-source law installation
path and generated-controller correspondence remain open. No old generated subject,
normal-form presentation or compiled endpoint acts as a fallback.

Mathematical invariants and representation relations remain legitimate author inputs.
Source selection, frames, slots, continuations, ordered answer routing and generated
progress/capacity bookkeeping belong to the common implementation. Any new connection
between component mathematics should be stated against their reusable interfaces;
installing it at a call is a separate structural obligation.

Native associated-component exports retain their existing schema. The Lean
`structured-source components` command checks proposal association and reports
mathematical obligations as unresolved. It is not a law prover or security endpoint.
