# Concrete verification laws

This package connects retained mathematical interfaces to concrete IR meanings,
including helper contracts, table representations, uniform operations and field
encodings. It depends on the independent IR and Protocol packages.

The old native endpoint installations are retired. The registry retains logical
schemas but no installed compiled or executable security endpoint. Actual-source
law installation is developed against the shared Region/Process construction path.
See [support](../docs/support.md) and [components](../docs/spec/components.md).
