# Owner-view source-determinacy audit

This package asks one exact question: does the current migrated Interaction
profile determine the six PIR owner views, their canonical body grammar, their
source-authority envelope routes, and an exact required-read manifest without
borrowing a witness-local schema?

The frozen aggregate is `Affirmative/F1R1C-A-SOURCE-DETERMINACY`.

Run from the repository root:

```sh
python3 -B evaluation/formal-source-owner-views-f1r1c/run.py --check
```

Use `--json` for the complete evidence inventory.

## Source-authority alignment

This package audits the authenticated owner compiler definitions. It does not
form the fixture authority IDs consumed by the protocol and Analysis models.
Those executable identities changed when the protocol model began applying
the selected owner's tagged compiler equation instead of its former generic
six-field record. The current audit confirms that the required owner routes
exist; it does not freeze or authenticate those model-local identities.

## Evidence boundary

[`audit_model.py`](audit_model.py) compiles the current profile with the
Foundation-backed publication implementation, inspects its structured
artifacts, and re-admits the retained owner subject.
[`independent.py`](independent.py) separately parses the raw manifest with
duplicate-key rejection, extracts the marked source ranges, and reconstructs
the catalog, selectors, body functions, compiler routes, and required reads.
The 13 observations are frozen in
[`expected-findings.json`](expected-findings.json).

A pass establishes source determinacy for the exact current profile and the
bounded audited view set. It does not execute a durable view evaluator, issue
an owner capability, prove recursive read adequacy for arbitrary schemas,
establish implementation or backend correspondence, publish an identity,
prove a theorem or cryptographic property, or establish production support.
