# Semantic Closure Falsifier

This bounded package pressure-tests the cross-owner laws repaired during the
pre-freeze semantic audit. It is an adversarial model, not an implementation of
PIR and not evidence for a cryptographic theorem.

The package checks eight failure-prone seams:

1. every public and confidential operand of one run-grounding operation retains
   one object-identical execution basis;
2. endpoint support classification completes feature dispatch before reading a
   Plan-dependent continuation arm;
3. extractor counterfactual rights use the exact closed vocabulary and each
   right has a capability denotation; and
4. transport profiles retain references to owner-defined family contracts and
   the exact common Analysis failure partition instead of copying partial
   contract bodies or accepting prose labels;
5. every commitment-opening profile formation defect has an executable
   producer and multi-defect results retain the declared canonical order; and
6. duplex instance projection uses one explicit Foundation record encoding,
   preserves equal values at distinct bindings, and refuses a non-public
   Statement origin before transcript bytes exist;
7. duplex invocation-material preparation distinguishes wrong value kind from
   an exhaustive, canonically ordered set of semantic refusal reasons; and
8. every canonical same-Core Fiat--Shamir checker defect has one exact
   producing comparison and multi-defect results remain canonically ordered.

It also contains structural guards for the durable corpus: removed undefined
type names and prose failure-partition aliases cannot return, every durable
Markdown fence balances, every local Markdown file target exists, and the
documentation manifest is an exact nonduplicated inventory.

`reference_model.py` and `independent.py` implement the two composition-critical
classifiers separately. Tests require agreement over the full finite matrix and
include equal-looking but distinct run bases, mixed causal/replay sources,
duplex-plus-empty-continuation requests, copied family contracts, retired
counterfactual tags, malformed commitment profiles, and mismatched or late
duplex material.

Run:

```bash
python3 run.py
```

Passing means only that this finite falsification matrix did not find a
counterexample to the written local laws. It does not establish owner-profile
preimages, complete protocol-family coverage, recursive-composition validity,
implementation correspondence, or security.
